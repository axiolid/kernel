# axiolid-constraint2d

Apollonius and tangent-circle constructions (#159, ledger row B14): every circle tangent to three given points, lines or circles, in any combination, with every real solution returned rather than the first one found. Degenerate configurations -- three coincident objects, all-parallel lines with no enclosing circle, an unsolvable sign branch -- are refused by name, never silently dropped.

```bash
cargo add axiolid-constraint2d
```

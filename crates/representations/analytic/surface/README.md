# axiolid-surface

Exact, format-neutral surface values: planes, circular and elliptical
cylinders, cones, spheres, tori, and rational or polynomial B-spline
surfaces with their knot grids and weights kept as authored. It declares the
`SurfaceEvaluator` seam but evaluates nothing. Bounded, swept, offset and
curve-on-surface relationships are nodes in `axiolid-model`, not types
here.

```bash
cargo add axiolid-surface
```

# axiolid-guarantees

Provider-neutral vocabulary for what a geometric answer is worth: certified
values, signs that may be indeterminate, reported precision, and the
escalation ladder a provider climbs when a fast answer is not certain. It
depends on no representation or provider, so any contract can use it.

```bash
cargo add axiolid-guarantees
```
